# Frontier AI Capabilities Scorecard

A biweekly comparison of the latest flagship models from xAI, OpenAI, Anthropic, and Google: where each leads and lags, estimated researcher vs everyday-user reach, and real adoption data.

Live page: https://sip-coder.github.io/frontier-ai-scorecard/

Past editions are in `archive/`. Researcher and everyday-user percentages are estimates, not measured figures.
