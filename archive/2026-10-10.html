Frontier capabilities gap

Latest flagships as of Oct 10, 2026 (PT). Updates the Sep 21 edition. Preference & independent indices cited; vendor tables treated as claims.

On the % columns: There is no public cross-lab study that measures “% of model capability unlocked.” Researcher / everyday-user % below are Katie estimates (how much of that model’s practical ceiling a typical user in each group can actually reach via access + habits), anchored on access tiers and Anthropic’s Claude Code study (novice verified success ~15% vs expert ~28–33%). Not measured facts. Where an estimate moved since Sep 21, the reason is stated next to it.

What changed since Sep 21

  • All four labs shipped. xAI Grok 4.7 (Sep 21) · Anthropic Claude Opus 5.5 (Sep 22), Sonnet 5.5 (Sep 28), Haiku 5.5 (Oct 7) · OpenAI GPT‑6 Sol/Luna (Sep 22), GPT‑6.1 Sol (Sep 29, DevDay), GPT‑6 in ChatGPT Chat for all tiers (Oct 7–8) · Google Gemini 4 Argon announced Sep 30 (gated, not public).
  • New #1 on independent intelligence: Claude Opus 5.5 (max) scores 58 on the Artificial Analysis Intelligence Index, up from the Sep tie of Astra / Fable 5.1 at 53.
  • New #1 on human preference: Gemini 4 Argon‑high leads LMArena Text (1525, preliminary, ~4.9k votes); Opus 5.5‑high is #2 (1507). Fable 5 slipped from #1 to #4.
  • Near-frontier got cheaper: GPT‑6.1 Sol hits AA 52 at ~1/5 of Astra’s token price ($2/$10); Opus 5.5 cut to $4/$20 (−20% per token, ~−40% typical cost per Anthropic).
  • More gating: Argon only for Fairwind cyber defenders + trusted testers; Opus/Sonnet 5.5 send cyber tasks to fallback models unless verified (CVP); OpenAI rates GPT‑6.1 Sol “Critical” for cyber. TechCrunch, citing the WSJ, reports that OpenAI dropped a planned GPT‑6.1 Astra over safety concerns.
  • Reach: ChatGPT now >1.2B weekly users (OpenAI), and GPT‑6 is now in the Free tier. Grok 4.7 improved on benchmarks but placed below Grok 4.6 on LMArena.

What the newest models can do as a whole

Shared ceiling

  • Selectable reasoning effort (up to 5 levels: low → max)
  • Tools: functions, code exec, search
  • Vision + 500k–1M context; output limits now 128k (Opus 5.5, 6.1 Sol) up to 1M (Argon)
  • Multi-hour agentic coding (e.g., 18-hour unattended runs; codebase-wide migrations)
  • Computer use is now in APIs (OpenAI Agents API; Claude OSWorld ~80%+)
  • Always-on / scheduled agents (OpenAI Dots, ChatGPT team tasks)

Real gaps that still matter

  • Preference: Argon (prelim) ≈ Anthropic > Gemini 3.8 Flash > GPT‑6.1 Sol > Astra > Grok 4.7
  • Independent AA: Opus 5.5 (58) leads; Astra ≈ Argon ≈ Fable (53); 6.1 Sol 52; Grok 4.7 46; 3.8 Flash 41
  • Access: Google’s best is gated; Anthropic & OpenAI gate cyber/bio use
  • Price: the ~$2-input tier now reaches near-frontier (6.1 Sol, Grok 4.7, Argon intro)
  • Distribution: ChatGPT 1.2B WAU + Gemini 1B MAU vs Claude & Grok far smaller

Are people using advanced features?

  • Agent surfaces are still a small slice: Codex + Work at 40M is roughly 3% of ChatGPT’s 1.2B weekly users (the two figures use different measures)
  • Default effort matters: the Claude apps default to Medium. Sonnet 5.5 scores 45.9% on the Coding Agent Index at medium vs 68.4% at max
  • Experts reach ~2× the verified success of novices (15% → 28–33%, Anthropic). No newer cross-lab study found
  • OpenAI’s answer is to make the UI do the work: Intelligent UI in Chat for everyone
  • Still no apples-to-apples “unlock %” across labs
