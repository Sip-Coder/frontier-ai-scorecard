What the newest models can do as a whole

Shared ceiling

  • Selectable reasoning effort
  • Tools: functions, code exec, search
  • Vision + long context (500k–1M+)
  • Agentic coding loops
  • Chat + API surfaces
  • Computer/browser use (varying maturity)

Real gaps that still matter

  • Preference: Anthropic (± Gemini Flash) > Astra early > Grok 4.6
  • Independent AA: Astra ≈ Fable; cost/task favors Astra
  • Computer use: OpenAI claims lead; Claude strong; Gemini Preview
  • Price: Gemini Flash / Grok cheap; Astra & Fable expensive
  • Distribution: ChatGPT + Gemini apps at ~1B; Claude & Grok smaller

Are people using advanced features?

  • Most volume is still basic chat (+ voice on Gemini)
  • Claude Code: users plan ~70%, model executes ~80%
  • Experts ~2× verified success vs novices (15% → 28–33%)
  • Gemini: voice in 63% of app use; Live camera/screen in 1/5 Live sessions
  • No apples-to-apples “unlock %” across all four labs
